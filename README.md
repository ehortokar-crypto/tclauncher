## What it does

- **Every Minecraft version** — 900+ releases, snapshots and old versions down to `rd-132211`, with the right Java bundled.
- **Mods without the hassle** — Fabric, Forge, NeoForge and Quilt; search mods and modpacks, compatible files and dependencies are picked automatically.
- **Play with friends** — rooms with no port forwarding, your own servers with backups, a friends list with presence.
- **Skin manager** — a skin catalogue with categories and filters, a free pixel skin editor, skins for offline nicknames.
- **AI assistant** — help with crashes, mods and builds, right in the launcher.
- **Statistics and badges** — playtime, sessions and achievements, synced with your account on the website.
- **45 themes** and seasonal event themes, interface in 15 languages.
- **Windows, Linux and macOS** — Java is already included.
